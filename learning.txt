The http referer header is to tell the current page where i am coming from. so when we click on a hyperlink, the request might include a Referer field which indicates the last page i was on (source : {wikipedia, developer.mozilla.org}).
It can be used for analytics, logs, content personalization and security (on which i will write next).
I would have hit this wall because leetcode wanted to know where i am coming from.
Referer header is used by the server to understand if the request is coming from their own website or someone is directly hitting the api/endpoint for scraping purposes or whatever.


CSRF or Cross-Site Request Forgery
___________________________________
A Cross-Site Request Forgery (CSRF) attack occurs when a malicious web site, email, blog, instant message, or program tricks an authenticated user's web browser into performing an unwanted action on a trusted site(owasp.org).
An attacker can cause harm if they have your session cookies.
CSRF is prevented by examining the header to see the source origin and target origin.



HOW I GOT AROUND
________________
very simple, just add a headers dict while sending the request.
headers = {
    "Content-Type": "application/json",
    "User-Agent": "Mozilla/5.0",
    "Referer": "https://leetcode.com",
    "Cookie": "csrftoken=token; LEETCODE_SESSION=session",
    "x-csrftoken": "token"
}
